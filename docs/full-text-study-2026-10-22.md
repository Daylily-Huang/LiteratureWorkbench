# 所选文献全文研读

## 使用

文献总览选择 1–8 篇 → 研读所选文献，或证据矩阵的比较维度入口 → 研究助手「所选 N 篇」。阅读方式默认「全文研读（全部解析文字）」。填写问题 → 检查全文（不调用模型）→ 查看每篇页数/字符数 → 点击提问才发送。

可主动切换「快速问答（检索片段）」。单篇普通问答、选区精读、全库检索、图谱关系候选沿用已有流程；本轮没有把这些入口标为全文。图谱候选仍基于检索并需人工确认。

## 完整性与证据

- 全文模式不检索、不切掉页尾、不做摘要代替正文；将每篇当前已完成解析的所有页面文字同次发送。不是模型已理解或科学核实的承诺。
- 检查总页数、连续页码、完成的解析批次、有效文献及来源库。缺页、未知总页数、无文字页均在模型调用前拒绝，需重新解析/OCR；没有自动跳过空页。
- 原文是解析文字，未进行图片视觉理解，表格结构与公式提取可能不完整。页面含少量文字并不证明图片也已被读取。
- 独立请求预算：最终序列化请求最多 256 KiB；超过要求减少篇数，绝不截断或偷偷退回片段。普通问答/翻译维持 64 KiB 上限。此为应用发送预算，不是对模型上下文容量的声明；服务商拒绝会显示失败。
- 在线模型仅在用户提交后调用一次；没有关键词扩展、自动重试、问答缓存或本地降级。仅本地设置下不发送。全文请求超时上限 120 秒；停止等待不保证服务器或提供商取消处理。
- 准备结果绑定每篇内容哈希、解析批次、名称及页数。提交前及模型返回后再次检查；来源变化不返回为当前证据。
- 模型按 JSON 给出逐条结论和原文引句。服务端核验选中文献、物理页及连续原句（只容许空白归一），任何一条错误均拒绝整份结果，不展示/归档成可信结论。核验失败可能已经计费，界面明确提示；不会自动再请求。
- 每条结论展示页码及已核对原句。引句真实不代表推论成立；跨篇关系与数值解释仍须人工核对。本次未引用的选中文献单独提示，不冒充已完成比较。
- 全文发送范围、版本、原句与回答一并归档到研究记录，界面与 Markdown 导出保留范围说明。不自动进入知识图谱。
