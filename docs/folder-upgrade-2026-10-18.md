# 多文件夹同步升级（2026-10-18）

用户需求：继续完善文献网站，重点回应多个本地目录的关联与新文献自动刷新。候选清单见 `folder-upgrade-2026-10-18-candidate.json`。

## 本轮功能

- 左侧“管理文件夹”：查看关联路径、PDF 数量、是否包含子文件夹、扫描队列/运行/失败状态、最近同步时间与遗漏提示。
- “添加本地文件夹”：通过系统选择窗口选目录，网页显示路径与子目录选项，明确确认后注册。取消不会注册；过期、重叠、文件夹身份变化等失败提供可读提示。
- “重新扫描”：针对选定目录排队扫描；后台运行时自动监听变化，文献列表每 3 秒刷新。
- 网站启动时为所有已关联且有效的监听目录安排补扫，补齐网站关闭期间的变化；直接导入的内部目录不被当作普通监听目录扫描。
- 文献来源加入独立 library_id；树目录与筛选按来源区分。来源名称显示父目录与当前目录，常见同名 papers 文件夹更容易辨认。
- 重复注册原目录时，拒绝悄悄忽略不同的子目录选项；已有同步范围保持不变。

使用入口：左侧 **管理文件夹 → 添加本地文件夹 → 系统选目录 → 确认关联**。文件保留原位置，已有批注写回原 PDF 的行为保持不变。本轮未替用户选取或新增实际文献目录。
