# PDF 批注深入测试与修复（2026-10-27）

本地网站已备份安装修复。隔离测试发现两个问题：Esc 关闭评论预览后，在同一标记内移动无法再次弹出；不同页面的 PDF 批注可能共用 /NM 名称，原先用该名称作为全篇唯一编号，会让其他页批注同时进入编辑状态，并可能操作错对象。

现在用页码和 PDF 对象引用识别批注；新编号与旧名称同时匹配多个对象时拒绝操作，避免改错；无歧义的旧编号继续可用。批注本身、历史记录和 PDF 没有批量改写。关闭预览时重置悬浮命中状态，允许同一范围再次显示。

验证：隔离后端15项、前端47项、TypeScript/Mypy/Ruff通过；Chrome 在临时PDF检查评论创建/重叠、Esc后重现、缩放后的去重、过期版本拒绝、跨页编辑、删除与撤销、90°旋转页选择及下划线；旋转页标记与文字范围在页面上重叠。初次自动化定位存在脚本选择器及 DOM 重新渲染导致的失败，修正等待/定位后通过，未将其作为已确认的产品故障。没有调用付费模型，测试密钥为空且请求仅限隔离本地站。

独立首审6次、针对已提出的编号歧义复验3次，最终 P0/P1/P2 均0、GO；首审部分源码输出截断，复验聚焦受影响范围，未重读全部源码。安装前后原始文献、既有笔记、批注、缓存及正式备份的旧记录和文件均保留；启动产生一条正常扫描任务。

安装记录、候选哈希、只读正式站验证及测试结果见同名 JSON。此轮没有针对所有PDF排版、所有外部编辑器或触屏进行穷尽测试。

测试临时目录已清理（795文件、69链接），未遍历链接目标；清理后再次核对原PDF、既有备份、批注、笔记和研读缓存。
