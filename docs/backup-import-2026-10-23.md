# 外部备份导入与迁移预检

本轮面向本地个人科研工作台。用户可以在“数据与备份”选择或拖入自己保存的 `.lwb.zip`，不需要先把文件放进程序目录。流式传输显示进度，可中止传输；传完后后台核验，支持取消与失败重试。核验通过后展示备份内部时间、原文件名、PDF覆盖范围；用户再手动恢复、打开独立工作台。导入不会替换当前库，不自动启动恢复服务或调用AI。

## 文件与数据边界

- 文件存入系统生成的UUID位置，文件名只作显示，不接受客户端提供保存路径。只允许一个数据任务；未完成传输、断开、重启和取消不会成为可启动的恢复工作台。
- 校验压缩包文件清单、逐项大小与SHA256、数据库完整性与外键，以及活动文献和批注恢复依赖。限制压缩目录元数据、文件数量和总展开大小，拒绝Windows不支持的路径、大小写冲突、加密项，以及运行配置/旧备份等非白名单载荷。单份传输上限约100GiB，展开上限100GiB；实际可用大小还受磁盘空间影响。
- SQLite在读取外部库时关闭trusted_schema，并将数据库结构及迁移版本与当前15次迁移生成的参考库逐项核对；未知/被改动的结构不导入为可用备份。参考[SQLite安全建议](https://www.sqlite.org/security.html)。ZIP预检使用当前固定的CPython3.12结构定义；升级Python时须重新验证兼容性。
- 同一归档再次导入时，重新核验传入文件，并核对已保存文件的实际哈希后复用；已损坏的旧副本不当作成功去重。数据库备份明确不能恢复成完整可读文献库，未核验的失败记录不猜测覆盖范围。
- 上述是文件一致性、版本兼容和恢复可用性核验，不是数字签名或来源身份认证。应导入自己可信保存的本站备份，不能据“核验通过”推断论文内容/AI结论正确。导入不包含API密钥或模型权重，新机器仍需安装和配置；已就绪副本不能直接改位置后继续使用。
