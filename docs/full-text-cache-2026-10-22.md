# 全文研读缓存与分析复用

## 使用与费用

「所选 N 篇 → 全文研读」先检查再提问。默认勾选「新问题优先复用已有分析」。

- 同组文献、正文指纹、模型、研读规则与相同问题命中缓存：本地返回旧回答，0 次云端模型调用。重启网站后仍保留。
- 新问题有兼容的已有全文研读：优先提供最多 3 次先前研读的分析与核验引句，仅在序列化输入实际更小时采用。生成新回答仍有 1 次 API 调用；标记「复用分析生成 · 本次调用 API」。这些笔记不是本次重读全文。
- 没有可用分析/复用并不省输入：提供完整解析文字，预检就明确显示将调用 API。
- 可明确勾选「跳过缓存，重新读全文（会调用 API）」；检查计划后才提交。成功后此选项自动取消，避免下一题忘记切回。
- 不宣称新问题免费，不按关键词模糊套用旧答案，不自动追加一次全文请求。复用引句不足时应说明证据缺口，由用户选择重读。

## 正文与证据边界

缓存指纹逐篇绑定文献身份、物理页边界及归一空白后的全部正文；不把 PDF 文件哈希、解析批次或批注当作正文变化。改正文/换篇/换模型/改研读规则会隔离旧缓存；仅高亮、评论、PDF 元数据变化且正文不变仍可复用。调整同组选篇顺序不影响命中，但原文引用按文献身份重新编号。

缓存回答和复用笔记均再次核验当前来源页的连续引句，重新生成当前文献名称与内容版本的引用。复用回答只能引用本次笔记提供的原句范围；即使某句话确实存在于未发送的其他正文，也不能冒充本次已收到的证据。既有分析属于不可信 AI 材料，不能替代科学验证；没有自动入图。

免费检查与提交的发送计划（模型、正文、问题、上下文、缓存）有指纹约束。缓存丢失或计划变化时，禁止把本来免费的操作悄悄变成付费；需重新检查。若同题答案刚生成可直接转为免费命中。16 个进程内有界锁让同题并发请求共用首次完成的缓存，不重复调用；正式启动器原有单实例约束保留。

缓存不可读取时默认停止以免意外收费；缓存写入失败则返回已核验回答并提示可能无法复用，不自动再请求。失败、伪造引用与过期答案不作为合格缓存保存。研究记录与 Markdown 保留缓存/复用/新全文的来源方式。
