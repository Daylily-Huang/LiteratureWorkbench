# 按篇复用与增量全文对比

## 操作与实际费用

A+B 完成有依据的全文研读后，文献总览加选 C → 研读所选文献 → 检查全文。清单按篇显示「A/B：复用分析/引句，C：读全文」。点击提问后，一次请求提供 C 的全部解析文字及 A/B 旧分析和核对引句，一起回答对比问题；不会先另付费读 C 再另付费合并。

默认开启「旧篇和新问题优先复用已有分析」。继续加入 D 时，前一次确实读过且有核验引句的 C 也可复用。去掉 A/B 后，C/D 可单篇匹配，不能夹带未选篇内容。正文变化只让变化篇重新提供全文；旧篇缺少可用引句时也会明确列为读全文，不假称分析覆盖。

新对比仍需一次 API 调用；旧笔记和引句也是输入，可能计费，不承诺新增一篇等于只收该篇费用，亦不承诺小文献下必然更省 token。相同整组/同题缓存命中仍为零模型调用。主动跳过缓存会明确重读全部选择篇；成功后选项复位。没有自动付费补读或重试。

## 依据隔离

- 持久成员表绑定缓存记录、文献身份、逐页正文指纹和当时全文/分析复用方式。复用需实际全文发送记录和该篇至少一条当前可核对引句，别篇记录不代替它。
- 混合请求中，旧篇只能引用本次提供的已核验引句；新增篇允许引用本次提供的全部解析页。每条引句仍核对当前原文、物理页，失败不存合格缓存。
- 原组有任一篇被移除或正文变化时，保守丢弃整条旧组结论，只保留当前仍匹配篇的原文引句；不把 A+B 结论改称 A 单篇事实。原组完整有效则可复用原分析，仍按不可信 AI 材料处理。
- 旧 v1 整组缓存显式兼容：相同组/题可核验后免费返回；扩大选择时，在原组完整保留且正文指纹匹配原 scope 哈希的条件下复用。成功的新回答后才把已证实全文与引句的旧篇登记为成员。没有在迁移时凭空补科学结论；老缓存若只保留子集而缺乏逐篇证明，则不猜测命中。
- 新 v2 计划绑定逐篇方式、全部正文版本和实际上下文。计划改变必须重新检查，不能把原本复用计划悄悄改成整组全文付费。
- 逐篇各取最多16个候选，再合并有限上下文，优先保留全文来源证明。混合输入过大时停止，不因大小优化而悄悄重发旧篇全文。标题/批注/解析批次变化仍沿用已有正文缓存规则。
- 全文始终指已解析文字，不含图片视觉理解；引句真实不代表推论已经科学验证。没有自动入图。
