# 个人科研使用指南

从桌面“文献工作台”打开，当前地址为 http://127.0.0.1:59978/。端口可用时重启沿用；若发生端口占用，以启动器实际打开的地址为准。

## 日常精读

- 在主阅读区打开论文，可用标签切换，或将第二篇放到右侧并排；中间分隔条可拖动。点击哪侧，助手与批注面板就跟随哪篇。两侧栏可收起或调整宽度。
- 选中文字后可翻译、高亮、下划线、评论或“问 AI”。选区提问先进入助手草稿，补充问题并点击提问才发送；核对助手显示的论文与页码。
- 已有评论可在原文批注处悬停查看。复制文本会清理多余换行和跨行断词；用原文证据时仍以来源摘录和页码为准。
- 翻译框角落标明缓存/新翻译。排版变化或添加批注后优先复用相同原文译文；选区改变后以实际缓存提示为准，不能承诺所有新文本免费。

## 多篇全文研读与节省重复调用

1. 在“文献总览”选定论文，向所选文献提问，或从“联读与图谱”保存为研读组；每组最多8篇。
2. 助手选择“全文研读（全部解析文字）”，写好问题后点“检查全文”。检查本身不调用AI，展开清单查看每篇是读全文、复用分析/引句，还是直接命中缓存回答。
3. 核对范围后再点提问。增加一篇时，旧篇优先复用已核验分析/引句，新增或变化篇提供全文；新的合并回答仍可能产生一次API费用。
4. 相同问题、选篇顺序、来源版本和模型设置下可命中已有回答；改变顺序需要重新检查。“跳过缓存，重新读全文”是主动付费重读入口。
5. 文献列表可按AI研读状态筛选，进入“全文研读缓存”查看旧分析和原文依据，复制或导出；查看、导出不会调用AI。缓存保存失败时先保存当前回答，勿假定下次免费。

全文指解析出的全部文字，不包含图片视觉理解，也不保证表格或公式解析无误。缺页、解析未完成或超出请求上限会阻止全文提交；快速片段问答是另一个明确标识的模式。

比较问题可以这样写：“比较这些论文的研究对象、采样设计、关键假设、估计量与局限，每项附原文引句及页码；研究条件不一致时分开说明，区分真正冲突、方法差异和证据不足。”

## 从证据到知识图谱

1. “联读与图谱 → 证据矩阵”查看已保存问答和来源，按问题搜索，可对照两处原文或导出全部筛选结果。
2. 在“AI关系审核”填写研究问题，默认全文/增量模式；先点“免费检查全文与复用范围”，再明确提交分析。刷新、恢复和重复查询不会自动重新发送付费请求；状态不明时先查询原请求，勿立即重试付费分析。
3. 每条候选核对左右原句和方法/样本/条件，再修订关系类型与说明。明确确认后才入图谱；“支持”“分歧”或“方法对照”均不代表科学结论已验证。
4. 已有全文缓存结论也可选双侧依据转入审核，不调用AI；关系方向由你判断，转入后仍须确认。原组来源变化时需先重新核对。
5. 图谱可搜问题、关系说明和原文引句，并按关系类型与来源变化筛选。点击节点看关联，使用“对照两处原文”返回双栏；导出保留当前筛选下的全部匹配关系和依据。

## 笔记与保全

- “研究记录”中的个人思考自动保存，留意保存/冲突提示；断线时保留本机草稿。浏览器草稿按工作台与地址隔离，不等于已写入数据库或已备份。
- 成功保存的PDF批注写入PDF；研究问答、个人思考、图谱和翻译/研读缓存保存在工作台数据中。只复制PDF不能带走全部科研记录。
- 在设置的“数据与备份”建立、核验和下载完整备份；恢复先生成独立工作台，不覆盖当前库。源文献与正式备份应保留，测试副本和可重建开发缓存可清理。
- 本轮没有调用真实付费模型做验证。自动检查验证流程和引句匹配，AI对研究结论的解释仍需结合原文判断。
