# 研究笔记自动保存与按需读取

本轮补齐“核对原文后留下自己的判断”的日常可靠性。[Zotero笔记说明](https://www.zotero.org/support/notes)介绍随输入保存的使用习惯，[阅读器说明](https://www.zotero.org/support/pdf_reader)强调笔记中保留返回PDF的来源。本次采用自动保存与来源连续性，仍将AI原回答、历史引句和个人思考分开。

## 最终行为

- 研究记录列表每页30条，只传摘要；打开一条才读取完整回答与证据。支持跨全部记录搜索问题、回答、思考和原文引句，Unicode大小写与多词匹配，收藏筛选与分页。缓存入口可直接读取指定记录，不受列表当前页限制。原先完整列表接口保留兼容，新的界面不再请求它。
- 停止输入1秒后自动同步笔记，保留“保存笔记”按钮与导出。输入时先保存浏览器草稿，不等网络回执；切换记录、关闭弹窗后可显式恢复或导出未同步草稿。同步只修改标题、思考和收藏，不请求AI、不修改原回答或引句。
- 新笔记固定客户端生成的UUID，重试同一创建不会生成重复记录。更新仍严格使用版本号；回执丢失后只读核对当前值，相同才确认成功，绝不读取新版本号后强行覆盖。
- 多窗口冲突时保留各自草稿，不自动合并或覆盖。可以载入服务器版本，也可以另存带原问答、选篇和证据的副本；副本由服务器复制来源，并记录原记录ID。读取服务器版本期间又有输入时，不替换当前编辑内容。
- 已成功同步的草稿按精确快照清理，不删除后续输入；冲突草稿始终保留旧版本号，关闭/恢复不能把旧文字伪装成新版本。浏览器草稿按工作台和编辑实例隔离，另一工作台或另一窗口的草稿不被误删。
- 长回答与证据默认折叠，思考区可直接编辑；来源仍能返回PDF页码。原文变化时保留历史原句和版本提示，不伪装成当前有效依据。导出副本也保留原记录ID与来源。
- 读取/写入有15秒请求时限，失败后可重试；保存结果不确定时最多另用8秒只读核对。断线期间草稿仍保留；浏览器存储失败时明确提示，关闭前要求确认并提供导出。
