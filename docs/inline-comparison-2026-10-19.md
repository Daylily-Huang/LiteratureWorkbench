# 主阅读区并排对照与可调整翻译框

用户要求：两篇文献直接左右并排、中间拖动调整大小，翻译框可自由调整大小。

## 使用
- 打开论文后点击「左右并排」；也可点击其它论文标签上的 ⇥，将其放到右侧。
- 右侧下拉框可选择其它文献；「交换左右」保留各篇页码和缩放，「单篇研读」将右篇切回完整阅读器。「退出并排」保留左篇。
- 拖动中线调整25%–75%的宽度比例；双击均分，方向键微调。左右独立翻页、缩放与查找，适合宽度保持当前物理页可见。
- 助手与批注明确对应左篇；右篇可划词翻译，需批注时可交换到左侧或单篇研读。右侧不显示无效的批注按钮。
- 翻译框拖动标题移动位置，拖动右下角 ◢ 调整宽高；「重置大小」恢复自动尺寸。内容内部滚动，标题/关闭/缩放手柄保持可达；窗口缩小时限制在可视范围内。
