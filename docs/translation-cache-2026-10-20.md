本轮仅调整选区翻译、缓存存储与翻译框；文献库、批注和知识图谱数据不改变。

## 行为

- 缓存按文献、物理页、已核验页面正文、模型、语言和提示词版本隔离。高亮或评论造成 PDF 文件版本变化，但页面正文相同时，继续复用已有译文。
- 精确重复选区直接读本地缓存。扩选只在完整句段边界复用，不对句内否定词、数字变化做模糊拼接；新增部分仍需翻译。
- 缩选只有整段缓存时，默认显示“整段缓存参考”、完整原文及原译文，明确不是短选区的精确翻译。用户点击“仅翻译当前选区（可能产生 API 费用）”才请求短选区新翻译。
- 翻译框区分本地缓存、部分缓存、整段缓存参考和新翻译；云端请求尝试过即保留提示，不能因本地备用结果而声称本次完全没有云端请求。
- 成功的新片段及时保存；后续片段失败后重试可以复用先前成功部分。历史译文需重新核对保留的页面解析和上下文，无法确认则不复用。
- 缓存来自原有模型结果，并不代表翻译已经人工核验。段落参考和句段拼接不会推断逐词对应关系。
