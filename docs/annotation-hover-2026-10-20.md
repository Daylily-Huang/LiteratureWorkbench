# 原文悬停批注

已安装至当前网站 `http://127.0.0.1:60582`，刷新页面即可使用。桌面启动图标仍为稳定入口。

- 鼠标在批注文字上停留约 350 毫秒后显示评论、页码、只读标记及可展开的原文。
- 移到浮窗内可以阅读和滚动长评论，离开后延迟收起；Esc、阅读区滚动、缩放、拖选和文献切换会关闭旧预览。
- “在笔记中查看”沿用原有批注定位和活动文献切换；左右并排均可使用。
- 无评论的高亮明确显示“尚未填写评论”，不把原文当成用户评论。
- 浮窗继承网站明暗主题；仅展示已加载的本地批注，不发起模型请求或修改 PDF。

验证：TypeScript、生产构建、38 文件共 179 项前端测试通过。隔离真实 PDF 与 Chrome 验证了长评论滚动、Esc 收起、批注区域拖选、右侧独立评论及助手跟随；观察到 0 次批注或翻译写请求。截图检查修正了初版浮窗主题继承问题，并再次验证背景色及呈现效果。
